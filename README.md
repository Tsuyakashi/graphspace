# Graphspace

Личная платформа для проектов: доки, схемы, офисные файлы и ссылки на инфраструктуру в одном каталоге узлов.
Платформа хранит, связывает и показывает; редактируют Craft-приложения и Excalidraw.

Сейчас это МВП для одного пользователя на своей машине или в домашней сети.

## Запуск

```bash
npm run setup        # зависимости и сборка интерфейса, один раз
./setup-craft.sh     # веб-сборки Craft в ./craft (нужен gh); можно выборочно: ./setup-craft.sh wordcraft gridcraft
npm start            # http://127.0.0.1:4680
```

Нужен Node 24 или новее: сервер использует встроенный `node:sqlite` и не имеет зависимостей.
При первом запуске создаётся демо-проект Orbit. Без Craft всё работает, кроме редактирования офисных файлов, PDF и макетов.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT`, `HOST` | `4680`, `127.0.0.1` | Адрес сервера |
| `GRAPHSPACE_DATA` | `./data` | База и блобы; резервная копия — этот каталог целиком |
| `GRAPHSPACE_CRAFT_DIR` | `./craft` | Веб-сборки Craft, по каталогу на приложение |
| `GRAPHSPACE_AUTHOR` | имя пользователя ОС | Автор версий |
| `GRAPHSPACE_SEED` | включено | `0` — не создавать демо-проект |

Авторизации нет. Наружу сервер выставлять только за Tailscale или обратным прокси с входом.

## Что умеет

- **Узлы одного вида.** Проект, направление, аппка — один и тот же раздел с произвольной меткой. Детей может иметь любой узел: к репозиторию можно прицепить его доки. На верхнем уровне может жить что угодно, проект можно вложить в другой раздел и вынести обратно.
- **Смена корня.** Любой узел с содержимым становится корнем: двойной клик, хлебные крошки, «Сделать корнем». Корень, выбранный узел и фильтр хранятся в адресе страницы.
- **Виды.** «Все доки отсюда», «все git отсюда» — фильтр по типу от любого корня, деревом или плоским списком. Ничего не хранится, это запрос.
- **Граф.** Область от корня слоями слева направо. Сплошная линия — «лежит внутри», пунктир — «пользуется по ссылке». Фильтр по типу приглушает всё, что не на пути к подходящим узлам. «Граф отсюда» есть в меню, в шапке узла и в карточке на графе.
- **Общие узлы.** У узла один дом, в остальных местах он показан ссылкой. Общим может быть и ресурс, и раздел целиком.
- **Доки.** Markdown со вставками: `![[id]]` — узел, `![[id|type=doc]]` — все доки из области узла, включая будущие, `![[id@имя]]` — закреплённый снапшот. Вставленное читается из узла, а не копируется.
- **Версии.** Сохранение не перезаписывает: каждое создаёт версию. Версия с именем — снапшот. Правка поверх устаревшей версии ложится рядом как конфликтная.
- **Редакторы.** docx, xlsx, pptx, pdf, fig — веб-сборки Craft в iframe по протоколу `ready / open / save / dirty`. Схемы — Excalidraw. Экспорт в другой формат ложится рядом отдельным узлом.
- **Открыть нативно.** Сервер выгружает файл, запускает установленное приложение Craft и превращает каждое сохранение в версию. Работает, когда сервер и рабочий стол — одна машина.
- **Остальное.** Загрузка файлов и перенос узлов перетаскиванием, быстрый переход по Ctrl+K, корзина с возвратом, живое обновление открытых вкладок.

## Проверка

```bash
npm test             # API: вложенность, перенос, версии, конфликты, ссылки, корзина
npm run test:e2e     # браузер: дерево, виды, граф, вставки, правка дока, схемы и docx
```

Сквозному тесту нужны собранный интерфейс и Chrome (`CHROME=/путь`, по умолчанию `/usr/bin/google-chrome`). Шаг с WordCraft пропускается, если сборки нет. Вторым аргументом можно передать каталог для скриншотов: `node tests/e2e.mjs tests/shots`.

## Устройство

| Файл | Что в нём |
|---|---|
| `server/db.mjs` | Узлы, связи, версии, блобы по sha256 |
| `server/index.mjs` | API, события, раздача интерфейса и Craft с одного origin, нативное открытие, превью docx |
| `server/seed.mjs` | Демо-проект |
| `web/src/model.ts` | Область узла, фильтр по типу, строки дерева |
| `web/src/App.tsx` | Дерево, смена корня, фильтры |
| `web/src/Graph.tsx` | Раскладка и отрисовка графа |
| `web/src/NodeView.tsx` | Экраны узлов и версии |
| `web/src/Markdown.tsx` | Док и вставки |
| `web/src/Board.tsx`, `web/src/Craft.tsx` | Excalidraw и мост Craft |

Модель: `nodes(id, type, title, parent_id, props, ext, head)`, `links(from_id, to_id, kind)` с видами `uses`, `embeds`, `mentions`, `versions(node_id, n, blob, name)`.

Разработка интерфейса: `npm start` в одном терминале и `npm run dev` в другом, адрес `http://localhost:4681`.

## Чего пока нет

- Пользователей и прав.
- WebDAV и десктопного клиента; офлайна.
- Полнотекстового поиска: Ctrl+K ищет по именам и путям.
- Живого состояния внешних ресурсов: для git, S3 и registry хранятся только ссылка и заметка.
- Postgres и объектного хранилища: SQLite и каталог на диске.

Замысел и исходный запрос — в `docs/`.
