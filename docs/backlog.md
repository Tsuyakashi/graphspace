# Бэклог

Фаза концепта закрыта (ноябрь 2026): за основу взят этот код, прототип Opus — в архиве. Ниже — что осталось, по порядку. Каждый пункт: сделать → тесты → коммит.

## 1. Чтобы пользоваться каждый день

1. **Деплой в лабу.**
   - Dockerfile: Node 24, `npm run setup`, `./craft` монтируется томом.
   - Compose: том `data/`, порт только на tailnet.
   - Бэкап: снапшот SQLite (`.backup`) + rsync `data/blobs`.
2. **Авторизация через Tailscale.**
   - Пользователь из `Tailscale-User-Login` (через `tailscale serve`), разрешённый список в env.
   - Без заголовка — 401.
   - `author` версий — из логина.
3. **Шрифты для Craft.** Отдавать `storytold/craft-fonts` вместе с сервером. Без них WordCraft пишет «N fonts not installed», и вёрстка docx плывёт.
4. **Перенос одного реального проекта.** Критерий из концепта: неделю не открывать Notion ради него.

## 2. Десктоп

5. **WebDAV-проекция дерева** (концепт, раздел 7, этап 1). Смонтировать через Tailscale → `wordcraft /mnt/graphspace/.../file.docx`.
   - Перед реализацией проверить, как Craft сохраняет: в тот же файл или через временный файл + rename. От этого зависит, надо ли серверу склеивать rename в новую версию того же узла.
   - Блокировки: WebDAV `LOCK` ↔ мягкий lock узла.
6. «Открыть нативно» через схему `graphspace://open/<id>` для случая, когда сервер не на этой машине.

## 3. Качество

7. **Блокировка узла на время редактирования** (концепт, раздел 6). Сейчас есть только конфликтные версии.
8. **Полнотекстовый поиск:** FTS5 по именам и тексту доков, Ctrl+K ищет и по содержимому.
9. **Мосты Craft.** На 0.23/0.24 моста нет у PhotoCraft и VectorCraft. Следить за релизами и включить `psd`/`svg` как `design`, когда появится. Версии сборок закреплять (`CRAFT_<APP>_TAG`), обновлять только после проверки на своих файлах.
10. **Превью без `wordcraft-cli` на сервере.** Сейчас превью docx есть, только если CLI в PATH. Положить CLI в Docker-образ.

## 4. Потом, если понадобится

- Postgres вместо SQLite — когда появятся совместные проекты с несколькими людьми.
- Живое состояние ресурсов: коммиты и PR для git, список объектов S3, теги registry. По одному коннектору, только после MVP.
- Права на корень проекта для совместных проектов.
- Десктоп-оболочка на Tauri — если монтирования окажется мало.
- Идемпотентные ключи на мутациях — задел под офлайн-клиент. В прототипе Opus было `/api/ops` + `idempotencyKey`.

## Известные факты о Craft (проверено руками, ноябрь 2026)

- **Мост:**
  - `?host=parent`, только same-origin, контракт `"1"`.
  - WordCraft: `ready.file === false` — открывает байты, не `File`.
  - `window.<app>.execute / docInspect / commands` — управление из страницы.
- **CLI:** `wordcraft-cli convert` (md → docx → pdf), `render`, `--control PORT`, MCP.
- **Упаковка:** у PhotoCraft 0.23.1 сломана веб-сборка (`snippets` не в `app/`). `setup-craft.sh` это чинит.
