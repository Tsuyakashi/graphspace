# Graphspace

Личная платформа для проектов: каталог узлов, редакторы по типу, версии. Фаза концепта закрыта, дальше идём от этого кода **без переписывания**.

- Что умеет и как запускать — `README.md`.
- Замысел и спорные решения — `docs/concept.md`.
- Что делать дальше — `docs/backlog.md`. Берём задачи оттуда по одной.

## Стек
- Сервер: `server/*.mjs`, Node 24, `node:http`. Данные — Postgres (`pg`, единственная зависимость сервера), блобы — S3 (`server/s3.mjs`, SigV4 без SDK).
- Интерфейс: `web/`, React 18 + TypeScript + Vite. Сборка — `npm run build`, отдаёт сервер из `web/dist`.
- Редакторы:
  - Craft — веб-сборки в `./craft`, ставит `./setup-craft.sh` по версиям из `craft-versions.json` (их поднимает Renovate), в git не входят. В образ их кладёт тот же скрипт;
  - Excalidraw — npm-пакет.

## Решения, которые не пересматриваем без явного запроса
- **Версии не перезаписываются.** Каждое сохранение — новая версия. Правка поверх устаревшей кладётся рядом конфликтной, head не двигается. Блобы адресуются по sha256.
- **У узла один дом** (`parent_id`). Всё остальное — ссылки `links(kind='uses')`. Множественного родительства нет. `embeds` и `mentions` строит только сервер из текста дока.
- **Узлы универсальны.** Дети у любого узла, на верхнем уровне — что угодно. «Проект», «направление», «аппка» — это только метка `props.label` на разделе.
- **Виды не хранятся.** «Все X отсюда» — это `scopeOf` + фильтр: потомки плюс ссылки `uses`, один шаг, без дублей.
- **Один протокол редакторов:** `<app>:ready / open / dirty / save / failed` через `postMessage`, same-origin. Craft раздаётся с `/craft/`. Патчей в сборки Craft не делаем, кроме фиксов упаковки в `setup-craft.sh`.
- **Внешние ресурсы — ссылка + свойства.** Секреты в `props` не кладём.
- **Пространства.** Владелец узла — владелец корня дерева (`nodes.owner`). Видно своё и поддеревья из `shares`. Чужое и несуществующее — одинаково 404. Каждый эндпоинт с `:id` начинается с `mustNode(id, user)`. Перенос между пространствами запрещён, корень общего раздела удаляет и переносит только владелец, делится только владелец.
- **Удаление — корзина.** Блобы не удаляются.
- **Вход — только Cloudflare Tunnel + Access.** Пользователь — из проверенного JWT `Cf-Access-Jwt-Assertion` (email в нижнем регистре), своей аутентификации и reverse-proxy нет. `AUTH_MODE=dev` — только для разработки, там же заголовок `x-graphspace-dev-user` для тестов доступа.

## Проверка — после каждой задачи
```bash
npm test                       # API, вход и доступ, node:test (нужны Postgres и S3: docker compose up -d)
npm run build                  # tsc + vite
npm run test:e2e -- tests/shots # браузер; шаг WordCraft — если есть ./craft/wordcraft
```
- e2e идёт на демо-наборе `orbit`: `tests/server.mjs` ставит `GRAPHSPACE_DEMO=orbit`. Демо `personal` — для ручной проверки.
- Изменения интерфейса смотреть глазами по скриншотам из `tests/shots`.
- Новая функция = новый шаг в `tests/api.test.mjs` и/или `tests/e2e.mjs`.

## Стиль
- Тексты интерфейса и комментарии — по-русски, коротко.
- Новая серверная npm-зависимость — только с явной причиной.
- Новый эндпоинт с узлом — тест на 404 от чужого пользователя в `tests/access.test.mjs`.
- Новый тип узла — только если он понадобился второй раз. Новый вид внешнего ресурса — это значение `props.kind`, а не тип.
